# פרויקט אומגה

אב-טיפוס ניתן למשחק של עיר פשע בעולם פתוח, בדפדפן (Three.js + WebAudio, בלי קבצי מדיה).

```bash
npm run dev                    # http://localhost:5173/omega/
npm run build                  # נבנה יחד עם שאר האפליקציות, תחת /omega/
npm run build:omega-artifact   # עמוד יחיד: dist-artifact/omega/omega.html
```

## מה מומש מתוך המפרט

| פרק | במשחק | קובץ |
| --- | --- | --- |
| 1.1 מיני-מפה | אובלית, מסתובבת עם המצלמה, זום לפי מהירות, בניינים בתלת-ממד קל, חרוטי ראייה (אפור/צהוב/אדום), אזור חיפוש, מפלס ‎-1 במנהרה | `hud.ts` |

## הבדלים מהמפרט

- שמות מותגים, דמויות וגופים מ-GTA ומהעולם האמיתי הוחלפו בשמות בדויים (רכבים, חברות, דמויות, משטרה).
  שמות הנשקים הם כינויי דגם גנריים.
- גרפיקה low-poly פרוצדורלית: אין טקסטורות 8K, Ray tracing או הרס מבוסס חלקיקים. ה-AI מבוסס חוקים ולא למידת מכונה.
- כל הצלילים מסונתזים, ולא הקלטות אמיתיות של מנועים.
- אין מצנח, אין פנים מבנים, והיחידות הנוחתות על גגות לא יורדות מהם.
