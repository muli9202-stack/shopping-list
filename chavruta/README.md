# „החברותא שלי”

חברותא דיגיטלית מבוססת בינה מלאכותית ללימוד תורה. הדף פתוח על המסך, החברותא בחלון קבוע לצידו, ומדברים בקול.
אפשר לשאול, לקטוע אותה באמצע, לפתוח מפרשים, לבקש המחשה, ולחזור למקום המדויק שבו עצרנו.

התכנון (מסכים, מקורות, זרימת שיחה, תלויות) נמצא ב-[PLAN.md](PLAN.md).

## הפעלה

### באתר

האפליקציה נבנית יחד עם שאר האתר ומתפרסמת ב-GitHub Pages, בכתובת האתר + `chavruta/`
(`https://muli9202-stack.github.io/shopping-list/chavruta/`). פותחים ב-Chrome או ב-Edge, במחשב או באנדרואיד.

### במחשב (פיתוח)

```bash
npm install
npm run dev            # ואז פותחים http://localhost:5173/chavruta/
```

### מה צריך כדי שהכול יעבוד

| רכיב | מה נדרש | בלי זה |
|---|---|---|
| הסברים חופשיים | **מפתח Claude API**. מזינים אותו במסך „הגדרות”. נשמר רק במכשיר. | **מצב הדגמה** (מסומן בכותרת): קריאה מהמקור, מפרשים, מילון מילים, המחשות ובדיקת טענות על ברכות ב׳ ע״א. |
| הקראה בקול | **קול עברי במכשיר**. ב-Windows: הגדרות ← זמן ושפה ← דיבור ← הוספת „עברית”. באנדרואיד: מנוע הדיבור של Google עם עברית. | כתוביות בלי קול. הפה של הדמות לא זז, כי אין שמע. |
| דיבור במיקרופון | Chrome או Edge, אישור מיקרופון וחיבור לאינטרנט (זיהוי הדיבור של הדפדפן) | הקלדה בתיבה למטה |
| מקורות | אינטרנט (ה-API הציבורי של ספריא, בלי מפתח) | עותק שמור במכשיר: ברכות ב׳ ע״א – ג׳ ע״א, משנה ברכות פרק א׳ ובראשית א׳, כולם עם מפרשים |

במיקרופון פתוח מומלץ להשתמש באוזניות. יש גם סינון הד שמזהה כשהמיקרופון קולט את קול החברותא עצמה.

| מקורות | ללא עלות (ספריא) | – |

הערכה גסה: תשובה קצרה עם הדף בהקשר היא כ-5,000 טוקנים נכנסים ו-500 יוצאים, כלומר כ-3 סנט ב-Opus 5.5.
מסך ההגדרות מציג את העלות בפועל של השיחה, לפי השימוש שה-API מדווח.

## איך זה בנוי

```
chavruta/src
├── core/          ספרייה: הפניות, פענוח פקודות, מילון שמות והגיות, לקוח ספריא, אימות ציטוטים, המחשות, כיסוי
├── brain/         engine.ts (מנוע התורות), claude.ts (Claude), demo.ts + demoContent.ts (מצב הדגמה)
├── speech/        tts.ts (הקראה ותנועת פה), asr.ts (זיהוי דיבור, השהיית חשיבה, קטיעה, סינון הד)
├── state/store.ts המצב המשותף: דף, קטע במוקד, מילה מסומנת, מה הושמע ומה נקטע, התקדמות
└── ui/            הדמות, הדף, הפירושים, ההמחשות, פס השליטה, מסכי משנה
```

- **הפרדה בין אחזור, כתיבה והשמעה.** האחזור מביא מספריא את הטקסט המקורי (והמפרשים על השורות שבמוקד, ותוצאות חיפוש כשהשאלה מבקשת מקור נוסף). המודל כותב צעדים קצרים (`say` / `open_commentary` / `illustrate` / `clarify` / `resume_pending`). המנוע בודק כל הפניה וכל ציטוט מול הטקסט, ורק אז משמיע, מדגיש ומסמן.
- **אמינות.** ציטוט שלא נמצא אות באות במקור שצוין (בלי תלות בניקוד) לא מושמע כציטוט: החברותא אומרת שלא מצאה. הפניה שלא קיימת נדחית. מקור המחשה שלא נמצא מוסר מההמחשה.
- **עצירה באמצע.** דיבור של הלומד בזמן שהחברותא מדברת (אחרי סינון הד), כפתור „עצור” או Esc עוצרים את זרם המודל, את ההקראה, את התור ואת הפה. השורה שנקטעה והשורות שלא נשמעו נשמרות. ההיסטוריה שנשלחת למודל כוללת רק מה שנשמע בפועל, עם סימון „נקטע כאן”.
- **תשובה ישנה לא נוגעת בדף חדש.** כל מעבר מקור מעלה מספר תקופה (`epoch`). צעד שהתחיל בתקופה קודמת לא מדגיש ולא מבצע פעולות.

## בדיקות

```bash
npm run chavruta:test       # 95 בדיקות יחידה: פענוח פקודות, א׳/ב׳, שיוך פירושים לשורה, אימות ציטוטים, תוכן ההדגמה
npm run chavruta:e2e        # 14 בדיקות דפדפן (Playwright) עם דיבור מדומה
npm run chavruta:live       # בדיקה מול ספריא החיה
npm run chavruta:coverage   # בדיקת כל שמות הספרים, מספר הדפים והמפרשים מול ספריא
```

אם Playwright לא מוצא דפדפן: `PW_CHROMIUM=/path/to/chromium npm run chavruta:e2e`.

### מה נבדק אוטומטית

| דרישה | בדיקה |
|---|---|
| פתיחת דף לפי בקשה בקול | „בוא נלמד ברכות דף ב׳ עמוד א׳” פותח את הדף, החברותא קוראת ומדגישה (e2e) |
| הבחנה בין עמוד א׳ לב׳ | פענוח (`ב.`, `ב:`, `ע״א`, „עמוד בית”, ספרות), טקסט שונה בכל עמוד, מעבר ‹ › (יחידה + e2e) |
| התאמת פירוש לקטע | כל דיבור של רש״י ותוספות קשור לשורה שלו, ואין לרש״י דיבור על שורה 2 (יחידה + e2e) |
| הדמות נשארת על המסך | הדמות, הדף, הפירוש וההמחשה גלויים יחד ולא חופפים, גם בטלפון (e2e) |
| עצירה באמצע משפט | ההקראה מבוטלת, הפה נסגר, השורה מסומנת „נקטע” (e2e) |
| חזרה נכונה להקשר | אחרי הסבר מילה חוזרים לשורה שנקטעה מתחילתה. „תחזור למקום שבו עצרנו” עובד גם אחרי מעבר לעמוד אחר (e2e) |
| הצגת מקור בלחיצה | „תראה לי איפה זה כתוב” מסמן את הדיבור, ולחיצה על הפניה בתמליל מסמנת את השורה (e2e) |
| שם מסכת לא ברור | „ברחות” מוביל לשאלה „התכוונת לברכות?” לפני פתיחה. עמוד חסר מוביל לשאלה „א׳ או ב׳?” (יחידה + e2e) |
| מקור חסר / ניתוק אינטרנט | בלי רשת: העותק השמור עובד, ומקור שלא נמצא בו מדווח ולא מומצא (e2e) |
| טענה מוטעית של הלומד | „רבן גמליאל אומר עד חצות” מקבל תיקון עדין עם לשון המשנה (e2e) |
| ציטוט שאינו קיים | „לא מצאתי”. גם במצב Claude, ציטוט מומצא נחסם (e2e עם תשובת API מדומה) |
| מעבר מקור בזמן הכנת תשובה | התשובה הישנה לא מושמעת ולא מסמנת בדף החדש (e2e) |
| נאמנות תוכן ההדגמה | כל ציטוט וכל מקור המחשה במצב הדגמה נבדק מול הטקסט (יחידה) |

## מה עדיין דורש חיבור או השלמה

- **ביקורת אנושית:** צריך שאדם בקיא בלימוד יעבור על מדגם הסברים, על שיוך המפרשים ועל ההגייה. זה לא נעשה עדיין. ההסברים הכתובים ידנית במצב הדגמה (ברכות ב׳ ע״א) ומילון המילים הם הדבר הראשון לבדוק.
- **הסברים חופשיים** דורשים מפתח Claude. הבדיקות האוטומטיות מדמות את תשובת ה-API. איכות ההסברים מול המודל האמיתי לא נמדדה.
- **קול ודמות:** הקראה בקול הדפדפן ודמות SVG מקומית. הפה מסונכרן לתחילת השמע, לסופו ולגבולות המילים, לא לפונמות. קול טבעי יותר ואווטאר מצולם דורשים שירות TTS או אווטאר חיצוני (לא נבחר, לא נבדק מחירון).
- **זיהוי דיבור:** תלוי בדפדפן (Chrome / Edge). הגיות אשכנזיות של שמות מסכתות (למשל „ברוכוס”, „שאבעס”) נתמכות בפענוח, אבל זיהוי הדיבור עצמו הוא של הדפדפן.
- **צילום דף ממהדורה מודפסת:** לא שולב. אין מקור מורשה עם API (היברובוקס חסום ואין לו תנאים ברורים). התצוגה היא טקסט דיגיטלי עם שם המהדורה והרישיון.
- **מקורות נוספים:** מכון ממרא (זכויות יוצרים, קישור בלבד), ויקיטקסט (מתוכנן), חיפוש גוגל (ה-API נסגר ללקוחות חדשים). פירוט במסך „מאגר והתקדמות”.
- **מצב הדגמה** מכיל הסברים כתובים רק לברכות ב׳ ע״א. בשאר המקורות הוא קורא את הטקסט והמפרשים ומפנה לחיבור Claude לשאלות חופשיות.
- **רישיון:** טקסט הגמרא המנוקד של ספריא (מהדורת וויליאם דייוידסון) הוא CC-BY-NC, לשימוש לא מסחרי בלבד. לכל מהדורה מוצג הרישיון שלה.

## הגרסה שבצ׳אט (Claude Artifact)

`npm run chavruta:artifact` בונה דף יחיד, ו-`node chavruta/scripts/build-library.mjs` בונה לצידו ספרייה מקומית מתוך הייצוא הציבורי של ספריא:
כל הש״ס הבבלי עם רש״י ותוספות, כל ששת סדרי משנה עם ברטנורא, כל התנ״ך, ורש״י, רמב״ן, אבן עזרא וספורנו על התורה (292 ספרים, כ-100MB).
בצ׳אט אין גישה לאינטרנט, ולכן הספרים מתפרסמים כקבצים לצד הדף ונטענים לפי הצורך.
Claude עונה דרך החשבון של הצופה (יכולת `sample`), בלי מפתח. המיקרופון לא זמין בצ׳אט: מקלידים, והחברותא עונה בקול.
אין בספרייה רש״י ותוספות על תמיד ואין ברטנורא על תענית, כי אינם קיימים בספריא. ברש״י על בבא בתרא הטקסט נגמר בדף כ״ט, כמו בדפוס, וממשיך רשב״ם, שעדיין לא נכלל.

## קול טבעי

החברותא בוחרת אוטומטית את הקול העברי הטבעי ביותר שיש במכשיר. הקולות העצביים „Hila” ו-„Avri” (Natural) זמינים בחינם בדפדפן Edge, במחשב ובטלפון.
כשאין קול כזה, משתמשים בקול של Google או של מערכת ההפעלה, ובהגדרות מופיעה הנחיה איך להשיג קול טבעי.
