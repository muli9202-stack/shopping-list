# „החברותא שלי” – תכנון קצר

## מסכים

| מסך | מה יש בו |
|---|---|
| **חדר לימוד** (ראשי) | במחשב: הדף באמצע, חלון פירוש לצידו (נפתח לפי בקשה) וחלון החברותא קבוע בצד. אפשר לגרור את המחיצות ולשנות גודל. בטלפון: פס חברותא קטן למעלה עם כתוביות, הדף מתחתיו והפירוש כמגירה. הדמות אף פעם לא מכסה את הטקסט. |
| **פס שליטה** | מיקרופון (פתוח / „לחץ כדי לדבר”), השתקה, עצירה, תיבת הקלדה, מהירות ועוצמה, כתוביות. |
| **בחירת לימוד** | המשך מהמקום האחרון, גמרא / משנה / חומש / פרשת השבוע, רמה ואופן לימוד. |
| **המחשה** | שכבה בתוך אזור הדף (לא על הדמות), מסומנת „המחשה להסבר”, עם הנחות ומקורות שאפשר ללחוץ עליהם. |
| **מאגר וכיסוי** | אילו ספרים, מפרשים ומהדורות זמינים, מה נבדק ומה חסר, ורישיון לכל מהדורה. |
| **הגדרות** | מפתח גישה ומודל, מראה וקול, רקע, פרטיות (מה נשמר, מחיקת היסטוריה), עלויות. |
| **עזרה** | הוראות שימוש ופקודות לדוגמה. |

## זרימת שיחה

```
מיקרופון/הקלדה ──► זיהוי דיבור (he-IL) ──► פענוח פקודה מקומי (ספר/דף/עמוד, „פתח רש״י”, „חזור”)
        │                                      │ ברור → פעולה מיידית │ לא ברור → שאלת בירור
        ▼                                      ▼
  הפרעה (barge-in): עוצר השמעה, תור,      אחזור: הקטע הנוכחי + פירושים פתוחים + המילה המסומנת
  תנועת פה וזרם המודל; שומר מה הושמע     + חיפוש בספריא → טקסט מקורי
                                               ▼
                                   כתיבת הסבר (Claude, או חברותא הדגמה ללא מפתח)
                                   פלט: צעדים {אמירה, סוג, מקור, הדגשה, פעולה}
                                               ▼
                                   אימות: הפניה קיימת? הציטוט נמצא בטקסט? שייך לדף הנוכחי?
                                               ▼
                                   השמעה (משפט אחר משפט) + הדגשה + תנועת פה
                                   כל משפט שהושמע עד סופו נרשם כ„נשמע”
```

המצב המשותף (`session store`) מחזיק את הדף הנוכחי, הקטע במוקד, המילה המסומנת, הפירושים הפתוחים, מה הושמע ומה נקטע, ו„תקופת הקשר” (epoch). כל תשובה נושאת את ה-epoch שבו התחילה. אחרי מעבר דף, תשובה ישנה לא מדגישה ולא מבצעת פעולות.

## תלויות

- **ספריא**: טקסטים. בלי רשת עובדת תמונת מצב מובנית (ברכות ב–ג, משנה ברכות פרק א, בראשית א, עם מפרשים).
- **Claude API** (מפתח של המשתמש, נשמר רק במכשיר): הסברים. בלי מפתח עובד מצב הדגמה מסומן.
- **דפדפן**: זיהוי דיבור (Web Speech API, בכרום) והקראה (speechSynthesis, נדרש קול עברי במכשיר).
- **דמות**: SVG מקומי מונפש, בלי שירות חיצוני.

## סדר פיתוח

1. מסלול מקצה לקצה: בחירה, הצגה, שיחה, עצירה, רש״י, הדגשה, המחשה והמשך מנקודת העצירה. (גרסה זו)
2. הרחבת מפרשים (ראשונים ואחרונים דרך `links`), ירושלמי, תוספתא ורמב״ם דרך פענוח השמות של ספריא.
3. לימוד בעיון: טבלאות שיטות שנבנות מהמקורות, מנגנון חזרות מרווחות, ייצוא סיכום.
4. קול ודמות פרימיום (שירות TTS או אווטאר חיצוני) לפי החלטת המשתמש ועלות.
