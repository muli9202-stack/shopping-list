# דף הנחיתה של המועדון – הוראות הפעלה

הדף נמצא ב־`public/club/`. זה אתר סטטי עצמאי (HTML, CSS ו־JS בלי תלויות ובלי שלב בנייה).
אפשר להעלות את התיקייה כמו שהיא לכל אחסון סטטי (Netlify, Cloudflare Pages, GitHub Pages, שרת רגיל).
בפריסה הקיימת ל־GitHub Pages הדף מתפרסם אוטומטית בכתובת `/club/`.

| קובץ | מה יש בו |
|---|---|
| `index.html` | דף הנחיתה |
| `config.js` | **כל ההגדרות** – כתובת הגיליון, וואטסאפ, אנליטיקס, פיקסל, מונה |
| `privacy.html`, `terms.html`, `accessibility.html` | טיוטות של מדיניות פרטיות, תקנון והצהרת נגישות |
| `og-image.png` | תמונת השיתוף לרשתות (המקור: `og.html`) |
| `club-setup/Code.gs` | הקוד שקולט את ההרשמות ל־Google Sheets |

## 1. שם המועדון ופרטי החברה

בקבצים מופיעים ממלאי מקום בסוגריים מרובעים. מחליפים אותם בכל הקבצים:

- `[שם המועדון]`, `[שם החברה]`, `[מספר]` (ח.פ.), `[טלפון]`, `[אימייל]`, `[כתובת]`, `[תאריך]`, `[שם רכז/ת הנגישות]`
- ב־`index.html` בכותרת התחתונה – גם את `tel:+972500000000`.

```bash
grep -rl '\[שם המועדון\]' public/club | xargs sed -i 's/\[שם המועדון\]/השם האמיתי/g'
```

## 2. הכתובת של הדף (לגוגל ולשיתוף)

ב־`index.html` מחליפים את `https://YOUR-DOMAIN/club/` בכתובת האמיתית (שלוש פעמים: canonical, og:url, og:image).
פייסבוק ווואטסאפ דורשים כתובת מלאה לתמונת השיתוף. לבדיקה: https://developers.facebook.com/tools/debug/

## 3. שמירת ההרשמות ב־Google Sheets

1. פותחים גיליון Google Sheets חדש.
2. **הרחבות ← Apps Script**, מוחקים את מה שיש ומדביקים את התוכן של `club-setup/Code.gs`. שומרים.
3. **פריסה (Deploy) ← פריסה חדשה ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. מאשרים את ההרשאות ומעתיקים את כתובת ה־Web app (מסתיימת ב־`/exec`).
5. מדביקים אותה ב־`config.js` בשדה `SHEET_ENDPOINT`.

גיליון בשם "נרשמים" נוצר אוטומטית בהרשמה הראשונה. מה הקוד עושה:
- בודק שהשדות תקינים (כולל נייד ישראלי ואישור פרטיות).
- לא רושם אותו מספר טלפון פעמיים. מי שנרשם שוב מקבל את קישור השיתוף הקיים שלו.
- שומר קוד שיתוף אישי לכל נרשם, ואת הקוד של מי שהפנה אותו (עמודה "הגיע דרך קוד") – כך רואים כמה כל חבר הביא.
- שומר את מקור ההגעה מהמודעות (`utm_source`, `utm_campaign` וכו').
- חוסם ניסיון להזריק נוסחאות לגיליון, ומסנן בוטים בעזרת שדה נסתר.

**כל עוד `SHEET_ENDPOINT` ריק**, הטופס במצב בדיקה: ההרשמה נשמרת רק בדפדפן ולא נשלחת לשום מקום. לא לפרסם מודעות לפני שממלאים אותו.

> אחרי כל שינוי ב־`Code.gs` צריך **פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה**, אחרת הכתובת ממשיכה להריץ את הגרסה הישנה.

## 4. וואטסאפ, אנליטיקס ופיקסל

ב־`config.js`:
- `WHATSAPP_NUMBER` – למשל `'972501234567'`. מפעיל את הכפתור הצף ואת הקישור בכותרת התחתונה.
- `GA_MEASUREMENT_ID` – מזהה Google Analytics 4 (`G-...`). נשלח אירוע `generate_lead` בכל הרשמה.
- `META_PIXEL_ID` – מזהה הפיקסל. נשלחים `PageView` ו־`Lead`, ו־`ShareReferral` בשיתוף.

קוד מעקב נוסף אפשר להדביק ב־`<head>` של `index.html` במקום המסומן.

## 5. מונה נרשמים (לא חובה)

`SHOW_COUNTER: true` מציג בפתיח "כבר X משפחות ברשימת ההמתנה". המספר נקרא ישירות מהגיליון, והוא מוצג רק
מהרגע שהוא מגיע ל־`COUNTER_MIN` – כדי לא להציג מספר קטן שמרתיע. אין שום מספר מומצא.

## 6. תמונת השיתוף

`og-image.png` (1200×630) נוצרה מ־`og.html`. אחרי שמחליפים את שם המועדון, מייצרים אותה מחדש:
פותחים את `og.html` בדפדפן בגודל 1200×630 ומצלמים מסך, או עם Playwright:

```bash
npx http-server public -p 8765 &
npx playwright screenshot --viewport-size=1200,630 http://localhost:8765/club/og.html public/club/og-image.png
```

## 7. לפני שמפרסמים – רשימת בדיקה

- [ ] הוחלפו כל הסוגריים המרובעים (`grep -rn '\[' public/club/*.html`).
- [ ] מדיניות הפרטיות, התקנון והצהרת הנגישות עברו בדיקה משפטית, והודעת ה"טיוטה" נמחקה מהם.
- [ ] `SHEET_ENDPOINT` מולא, ונשלחה הרשמת בדיקה שהגיעה לגיליון.
- [ ] כתובת הדף עודכנה בתגיות ה־OG, ונבדקה ב־Facebook Sharing Debugger.
- [ ] בדיקת נגישות בפועל (מקלדת, קורא מסך בטלפון) ועדכון הסעיף "הדף נבדק עם" בהצהרת הנגישות.
- [ ] מינוי רכז/ת נגישות ועדכון הפרטים בהצהרה.

## מה במכוון **לא** נמצא בדף

אין המלצות או ציטוטים, אין מונה מזויף, אין שמות של רשתות שיווק, ואחוזי ההנחה מוצגים תמיד כ"מתוכננים"
שייקבעו בהסכם עם הרשת. לא נאספים תעודת זהות, פרטי אשראי או כתובת מגורים מלאה.
אימייל נאסף רק כשדה רשות, ורק למי שסימן הסכמה לקבל עדכונים.
