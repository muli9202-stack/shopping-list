פרק 25 · הטריק של Wolfenstein 3D ו-DOOM

Raycasting: איך נולד ה-3D

ב-1992, מחשבים היו חלשים מכדי לצייר עולם תלת-ממדי אמיתי. אז מתכנת צעיר בשם ג׳ון קרמק מצא טריק גאוני. תכנס למבוך שבנוי בדיוק ככה.

הבעיה

בתחילת שנות ה-90, מעבד של מחשב ביתי היה חלש פי עשרות אלפים מטלפון של היום, ולא היו כרטיסי מסך תלת-ממדיים בכלל. לצייר אלפי משולשים 30 פעמים בשנייה? בלתי אפשרי. אבל אנשי חברת id Software רצו משחק שבו אתה בתוך העולם. הפתרון היה Raycasting (הטלת קרניים).

הטריק

הרעיון מבריק בפשטות שלו:

  1. העולם הוא בעצם מפה דו-ממדית של משבצות, כמו דף משבצות: קיר או רצפה. אין גבהים שונים, אין קומות.
  2. המסך מחולק לעמודות (למשל 320 עמודות).
  3. לכל עמודה, שולחים קרן אחת מהשחקן, בזווית שמתאימה לעמודה, ובודקים כמה רחוק היא הולכת עד שהיא פוגעת בקיר.
  4. מציירים בעמודה קו אנכי: ככל שהקיר קרוב יותר, הקו גבוה יותר. זה הכול!

במקום לצייר מיליוני פיקסלים בתלת-ממד, המחשב שולח רק 320 קרניים בדו-ממד. זה היה מספיק מהיר ל-1992, והעולם נראה תלת-ממדי לגמרי.

האלגוריתם: DDA

איך יודעים איפה הקרן פוגעת בקיר? אפשר ״לצעוד״ לאורכה בצעדים קטנים ולבדוק כל פעם, אבל זה איטי ולא מדויק. האלגוריתם החכם נקרא DDA: הקרן קופצת ישר לקו המשבצת הבא, אופקי או אנכי, מה שקרוב יותר. כך בודקים רק את המשבצות שהקרן באמת עוברת בהן, ולא מפספסים אף קיר.

// הרעיון (מפושט): לכל עמודה במסך
for (let col = 0; col < SCREEN_WIDTH; col++) {
  const angle = player.angle - FOV / 2 + FOV * col / SCREEN_WIDTH;
  const dist = castRay(player.x, player.y, angle);    // DDA: כמה רחוק הקיר?
  const corrected = dist * Math.cos(angle - player.angle); // תיקון עין-דג
  const wallHeight = SCREEN_HEIGHT / corrected;             // קרוב = גבוה
  drawVerticalLine(col, wallHeight);
}

הבאג המפורסם: עין-דג

כבה במעבדה את ״תיקון עין-דג״ ותסתכל על קיר ישר. הוא נראה עקום, כמו דרך עדשת עין-דג! למה? הקרניים בקצוות המסך הולכות באלכסון, ולכן הן ״ארוכות״ יותר מהקרן שבמרכז, גם כשהקיר ישר לגמרי. הפתרון: להכפיל את המרחק ב-cos של הזווית בין הקרן לכיוון המבט. שוב, טריגונומטריה פותרת בעיה אמיתית.

הצל והצבע

שני טריקים קטנים נותנים עומק: (1) קירות רחוקים כהים יותר, (2) קירות שהקרן פגעה בהם בצד ״אנכי״ כהים קצת יותר מקירות ״אופקיים״. בלי שום חישוב תאורה אמיתי, העין שלנו כבר ״רואה״ עומק ופינות.

מ-Wolfenstein ל-DOOM ומשם להיום

1992 Wolfenstein 3D: raycasting, קירות באותו גובה, בלי מדרגות.
1993 DOOM: שיטה מתקדמת יותר (BSP) שמאפשרת גבהים שונים, מדרגות, חלונות ותאורה. עדיין לא תלת-ממד ״אמיתי״: אי אפשר להסתכל למעלה ולמטה או לשים חדר מעל חדר.
1996 Quake: תלת-ממד אמיתי עם משולשים. אפשר להסתכל לכל כיוון.
1996-1999 כרטיסי המסך התלת-ממדיים הראשונים (3dfx Voodoo, Nvidia) נכנסים לבתים, ומשנים הכול.
היום Ray Tracing בזמן אמת: שוב שולחים קרניים, אבל מיליוני קרניים בכל פריים, שמשתקפות וחוזרות כמו אור אמיתי. הרעיון של 1992 חזר בגדול.

אגב, לקוד של DOOM יש מעמד אגדי: הוא פורסם כקוד פתוח, ומאז אנשים גרמו לו לרוץ על מחשבונים, מקררים חכמים, מדפסות ואפילו בדיקת הריון דיגיטלית. ״Can it run DOOM?״ הפך לבדיחה קבועה בעולם המחשבים.

פרויקט: raycaster משלך

לכתוב raycaster ב-JavaScript עם Canvas זה אחד הפרויקטים הכי מספקים שיש: בערך 150 שורות, ובסוף אתה מסתובב במבוך תלת-ממדי שבנית בעצמך. חפש ״raycasting tutorial lodev״: זה מדריך מפורסם (באנגלית) שכל מי שבנה raycaster קרא. תוספות מתקדמות: טקסטורות על הקירות, רצפה ותקרה, ודמויות (״ספרייטים״) בתוך העולם.
