Python: השפה השנייה

אחרי שאתה יודע JavaScript, ללמוד Python זה עניין של ימים, לא חודשים. הרעיונות זהים, רק ״הדקדוק״ שונה.

למה Python?

Python (פייתון, על שם קבוצת הקומיקאים ״מונטי פייתון״ ולא על שם הנחש) היא אחת השפות הפופולריות בעולם. היא נוצרה כדי להיות קריאה: קוד פייתון נראה כמעט כמו אנגלית. היא השפה הראשית של:

  • בינה מלאכותית ולמידת מכונה: PyTorch, TensorFlow, וכמעט כל מחקר AI.
  • מדע נתונים: ניתוח נתונים, גרפים, סטטיסטיקה.
  • אוטומציה: סקריפטים קטנים שעושים עבודה משעממת בשבילך: לשנות שמות ל-500 קבצים, להוריד נתונים מאתר, לשלוח הודעות.
  • שרתים: Django, Flask, FastAPI (אינסטגרם נבנה בהתחלה על Django).
  • לימוד: רוב האוניברסיטאות מלמדות אותה בקורס הראשון, והיא נפוצה מאוד בבגרות במדעי המחשב.
  • משחקים: ספריית Pygame למשחקים דו-ממדיים, ו-GDScript של Godot דומה לה מאוד.

ההבדל הגדול: הזחה

ב-JavaScript, סוגריים מסולסלים { } קובעים מה שייך למה. בפייתון אין סוגריים כאלה: ההזחה (Indentation, הרווחים בתחילת השורה) קובעת. זה מכריח לכתוב קוד מסודר, אבל גם אומר שרווח אחד לא במקום שובר את התוכנית.

if score > 100:
    print("ניצחת!")        # 4 רווחים = בתוך ה-if
    level += 1
print("הסוף")             # בלי רווחים = מחוץ ל-if, רץ תמיד

כוח-על של פייתון: רשימות מקוצרות

לפייתון יש דרך קצרה ואלגנטית ליצור רשימות, שנקראת List Comprehension:

squares = [n * n for n in range(10)]              # [0, 1, 4, 9, ... 81]
evens   = [n for n in range(20) if n % 2 == 0]   # רק הזוגיים
names   = [p["name"] for p in players if p["score"] > 1000]

משחק ראשון בפייתון: נחש את המספר

import random                         # ספרייה מובנית למספרים אקראיים

secret = random.randint(1, 100)
tries = 0
print("חשבתי על מספר בין 1 ל-100")

while True:
    guess = int(input("הניחוש שלך: "))   # int הופך טקסט למספר
    tries += 1
    if guess < secret:
        print("גדול יותר!")
    elif guess > secret:
        print("קטן יותר!")
    else:
        print(f"בול! ניחשת ב-{tries} ניסיונות")   # f-string: משתנים בתוך טקסט
        break                           # יוצא מהלולאה

איפה מריצים פייתון?

  • בלי להתקין כלום: Google Colab (מחברת בענן, מצוין ל-AI), Replit, או python.org/shell.
  • במחשב: מורידים מ-python.org, ומריצים ב-VS Code עם התוסף Python. בטרמינל: python game.py.
  • ספריות: מתקינים עם pip (כמו npm של JavaScript): pip install pygame.

פרויקטים מומלצים בפייתון

  1. נחש את המספר (למעלה) ואבן-נייר-מספריים.
  2. סקריפט שמסדר את תיקיית ההורדות: מעביר תמונות לתיקייה אחת, מסמכים לאחרת.
  3. משחק סנייק ב-Pygame.
  4. ניתוח נתונים: הורד קובץ CSV מ-Kaggle (למשל נתוני שחקני כדורגל) ועשה גרפים עם Pandas ו-Matplotlib.
  5. מודל AI ראשון: זיהוי ספרות כתובות ביד (מאגר MNIST) עם PyTorch ב-Colab. יש לזה אלפי מדריכים.
  6. בוט לדיסקורד (עם הורה, ובשרת שלכם).
