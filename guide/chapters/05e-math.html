מתמטיקה למתכנתי משחקים

״בשביל מה אני צריך את זה?״ הנה התשובה. כל דבר בפרק הזה משמש בכל משחק שאי פעם שיחקת, ותראה אותו זז מול העיניים.

לא צריך להיות גאון

רוב המשחקים משתמשים באותן 5-6 נוסחאות, שוב ושוב. לא צריך לזכור אותן בעל פה, צריך להבין מה הן עושות, ואז לחפש או לשאול AI איך כותבים אותן. בפרק הזה תבין אותן באינטואיציה, דרך ניסוי.

1. וקטורים

Vector (וקטור) הוא חץ: יש לו כיוון ויש לו אורך. כותבים אותו כשני מספרים (x, y), או שלושה בתלת-ממד. במשחקים וקטור מתאר כמעט הכול: מיקום, מהירות, כוח, הכיוון שהדמות מסתכלת, הכיוון לאויב.

  • חיבור וקטורים: מיקום + מהירות = המיקום הבא. זו כל התנועה במשחק!
  • אורך (magnitude): פיתגורס, Math.hypot(x, y). מרחק בין שני דברים = אורך ההפרש ביניהם.
  • נרמול (Normalize): לחלק וקטור באורך שלו, כך שנשאר רק הכיוון (אורך 1). ככה דמות זזה ״לכיוון השחקן״ במהירות קבועה.
  • מכפלה סקלרית (Dot Product): a.x*b.x + a.y*b.y. אם חיובי, שני החיצים פונים לאותו כיוון בערך. אם שלילי, לכיוונים הפוכים. משמש לשדה ראייה של שומרים, לתאורה (לאיזה כיוון המשטח פונה ביחס לשמש), ולזיהוי ״האם הכדור פוגע מלפנים או מאחור״.
// אויב שרודף אחרי השחקן: כל התורה בארבע שורות
let dx = player.x - enemy.x, dy = player.y - enemy.y;   // וקטור לכיוון השחקן
const len = Math.hypot(dx, dy);                        // המרחק
dx /= len; dy /= len;                                     // נרמול: רק כיוון
enemy.x += dx * enemy.speed * dt; enemy.y += dy * enemy.speed * dt;

2. סינוס וקוסינוס

כל פעם שמשהו מסתובב, מתנדנד או נע במעגל, יש שם sin ו-cos. הם עונים על שאלה אחת: ״אם אני מסתובב בזווית מסוימת, כמה אני זז ימינה (cos) וכמה למעלה (sin)?״

  • לירות לכיוון שהדמות מסתכלת: bullet.vx = cos(angle) * speed; bullet.vy = sin(angle) * speed;
  • תנועה מעגלית (ירח סביב כוכב, מגן שמסתובב סביב הדמות): x = cx + cos(t) * r; y = cy + sin(t) * r;
  • נדנוד: מטבע שמרחף למעלה ולמטה: y = baseY + sin(time * 3) * 5;
  • הזווית לאויב: ההפך מ-sin/cos הוא Math.atan2(dy, dx). מקבלים וקטור, מחזירים זווית. משמש לסיבוב צריח של טנק לכיוון המטרה.
מלכודת: מעלות ורדיאנים

בני אדם מודדים זוויות במעלות (360 בסיבוב). מחשבים מודדים ברדיאנים (2π, בערך 6.28, בסיבוב). Math.sin(90) לא שווה 1! צריך Math.sin(90 * Math.PI / 180). כל מתכנת משחקים נפל בזה לפחות פעם אחת.

3. אינטרפולציה ו-Easing: תנועה שמרגישה חיה

lerp (קיצור של Linear Interpolation) היא אולי הפונקציה השימושית ביותר בפיתוח משחקים: היא נותנת נקודה בין A ל-B, לפי t שבין 0 (ב-A) ל-1 (ב-B). כשמשנים את t עם פונקציית Easing, התנועה מאיצה, מאטה, או אפילו ״קופצת״:

טריק מפורסם: מצלמה חלקה שעוקבת אחרי השחקן. במקום לשים את המצלמה בדיוק על השחקן (קופצני), בכל פריים מזיזים אותה קצת לכיוונו: cam.x = lerp(cam.x, player.x, 0.1). התוצאה: מצלמה שמאחרת טיפה ״נגררת״ אחרי השחקן, וזה מרגיש קולנועי. העיר התלת-ממדית במדריך עושה בדיוק את זה.

4. עקומות בזייה

איך מציירים עקומה חלקה ויפה? עקומת בזייה (Bezier Curve) נבנית מכמה ״נקודות שליטה״. הקסם: היא נבנית רק מ-lerp, שוב ושוב.

איפה פוגשים את זה? בכלי העט בפוטושופ, פיגמה ו-Illustrator. בכל גופן שאתה קורא עכשיו (כל אות מורכבת מעקומות בזייה). במסלולים של רכבות הרים ומכוניות במשחקים. ובמסלולי מצלמה בסצנות קולנועיות.

5. אקראיות

Math.random() מחזיר מספר בין 0 ל-1. הנה הטריקים שחוזרים בכל משחק:

Math.floor(Math.random() * 6) + 1        // קובייה: 1 עד 6
arr[Math.floor(Math.random() * arr.length)] // פריט אקראי מרשימה
if (Math.random() < 0.05) dropRareItem();   // 5% סיכוי לשלל נדיר
min + Math.random() * (max - min)          // מספר עשרוני בטווח

מחשבים לא באמת יודעים להיות אקראיים. הם משתמשים בנוסחה שמייצרת מספרים שנראים אקראיים, מתוך מספר התחלתי שנקרא Seed (זרע). אותו seed = אותם מספרים בדיוק. ככה Minecraft יוצר את אותו עולם בדיוק לכל מי שמקליד אותו seed (תראה את זה בפרק על עולמות פתוחים).

6. מטריצות (הצצה)

בתלת-ממד, כל הזזה, סיבוב והגדלה של חפץ נשמרים בטבלה של 4×4 מספרים שנקראת Matrix (מטריצה). הכרטיס מסך מכפיל כל קודקוד במטריצה, ומקבל את המיקום שלו על המסך. לא צריך להבין את זה לעומק כדי להתחיל: המנוע עושה את זה בשבילך. אבל כשתגיע לזה בכיתה י׳-י״א, תדע בדיוק בשביל מה זה טוב.
