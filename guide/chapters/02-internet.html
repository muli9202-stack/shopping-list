פרק 2 · רשתות, שרתים ומנועי חיפוש

איך האינטרנט וגוגל עובדים

כשאתה שולח הודעה לחבר, היא עוברת דרך כבלים בתחתית האוקיינוס ומגיעה תוך פחות משנייה. בוא נבין איך.

מה זה בכלל האינטרנט?

ה-Internet (אינטרנט) הוא פשוט המון מחשבים שמחוברים זה לזה. מיליארדי מחשבים, טלפונים, שרתים ומצלמות, מחוברים בכבלים, בסיבים אופטיים, בגלי רדיו ובלוויינים. Inter זה ״בין״ ו-net זו ״רשת״, כלומר ״רשת בין רשתות״.

המידע באינטרנט עובר בעיקר דרך Fiber Optic (סיבים אופטיים): צינורות זכוכית דקים שבתוכם עובר אור. האור מהבהב (דלוק = 1, כבוי = 0) מיליארדי פעמים בשנייה. יש מאות כבלים כאלה בקרקעית האוקיינוסים, שמחברים יבשות שלמות, כולל ישראל.

לקוח ושרת

באינטרנט יש שני תפקידים חשובים:

  • Client (לקוח): המכשיר שמבקש משהו. הטלפון שלך כשאתה פותח יוטיוב.
  • Server (שרת): מחשב שנותן משהו. מחשב חזק של יוטיוב, שיושב בבניין ענק בשם Data Center (חוות שרתים), ושולח לך את הסרטון.

זה כמו מסעדה: אתה (הלקוח) מזמין מהמלצר, והמטבח (השרת) מכין ומחזיר לך את המנה. לחוות השרתים של גוגל, מטא ואמזון יש מאות אלפי מחשבים כל אחת, והן צורכות חשמל כמו עיר קטנה.

כתובות: IP ו-DNS

כדי שהודעה תגיע למקום הנכון, לכל מכשיר באינטרנט יש כתובת, כמו כתובת של בית. הכתובת הזאת נקראת IP Address (כתובת IP), והיא נראית כך: 142.250.75.14.

אבל אף אחד לא רוצה לזכור מספרים כאלה. לכן יש Domain (שם מתחם), כמו google.com. ומי מתרגם את השם למספר? מערכת בשם DNS, שהיא כמו ספר טלפונים של האינטרנט. כשאתה כותב google.com, הדפדפן שואל קודם את ה-DNS: ״מה המספר של google.com?״, מקבל כתובת IP, ורק אז פונה לשרת.

מה קורה כשאתה פותח אתר (שלב אחר שלב)

אתה מקליד כתובת←DNS מתרגם לכתובת IP←הדפדפן שולח בקשת HTTP←השרת מחזיר קבצים←הדפדפן מצייר את הדף
  1. אתה כותב בדפדפן youtube.com. Browser (דפדפן) זו התוכנה שמציגה אתרים: Chrome, Safari, Edge, Firefox.
  2. הדפדפן שואל את ה-DNS מה כתובת ה-IP.
  3. הדפדפן שולח לשרת בקשה בשפה מוסכמת בשם HTTP. הבקשה אומרת בערך: ״תן לי בבקשה את הדף הראשי״. היום כמעט תמיד משתמשים ב-HTTPS, שזה אותו דבר אבל מוצפן, כך שאף אחד בדרך לא יכול לקרוא את מה שנשלח.
  4. ההודעה מתחלקת לחתיכות קטנות בשם Packet (חבילה). כל חבילה עוברת דרך כמה Router (נתב), מחשבים שתפקידם להעביר חבילות בכיוון הנכון, כמו דוורים.
  5. השרת מחזיר קבצים: HTML (המבנה של הדף), CSS (העיצוב), JavaScript (ההתנהגות), ותמונות וסרטונים.
  6. הדפדפן מחבר את הכול ומצייר לך את הדף. כל זה לוקח חלקיק שנייה.
מה זה URL?

URL זו הכתובת המלאה של דף: https://www.youtube.com/watch?v=abc. יש בה: הפרוטוקול (https), הדומיין (youtube.com), הנתיב (/watch) ופרמטרים (?v=abc, איזה סרטון).

הענן

שמעת בטח את המילה Cloud (ענן). אין שום ענן בשמיים. ״הענן״ זה פשוט מחשבים של מישהו אחר, בחוות שרתים. כשהתמונות שלך ״שמורות בענן״, הן שמורות על דיסק במחשב של גוגל או אפל. חברות כמו Amazon (AWS), Google Cloud ו-Microsoft Azure משכירות מחשבים כאלה לכל מי שבונה אתר או אפליקציה. גם אתה תשתמש בזה כשתבנה אפליקציה.

איך גוגל עובד

באינטרנט יש מאות מיליארדי דפים. איך גוגל מוצא בתוך חצי שנייה בדיוק את הדף שאתה צריך? התשובה היא שלושה שלבים: זחילה, אינדוקס ודירוג.

שלב 1: זחילה (Crawling)

לגוגל יש תוכנות בשם Crawler (זחלן, נקרא גם Spider, עכביש, או Googlebot). הזחלן נכנס לדף, קורא אותו, ומוצא בו קישורים לדפים אחרים. אז הוא נכנס לדפים האלה, מוצא עוד קישורים, וכך הלאה, בלי סוף. כמו עכביש שהולך על קורים. ככה גוגל ״מכיר״ את רוב האינטרנט.

שלב 2: אינדוקס (Indexing)

גוגל לא מחפש בכל האינטרנט כשאתה מחפש. זה היה לוקח שנים. במקום זה, הוא בונה מראש Index (אינדקס): כמו האינדקס בסוף ספר לימוד, שאומר ״המילה דינוזאור מופיעה בעמודים 12, 45, 88״. לגוגל יש אינדקס ענק שאומר, לכל מילה, באילו דפים היא מופיעה. כשאתה מחפש, הוא רק מסתכל באינדקס, וזה מהיר מאוד.

שלב 3: דירוג (Ranking)

נניח שמיליון דפים מכילים את המילה ״משחק״. מי יופיע ראשון? כאן נכנס Algorithm (אלגוריתם) הדירוג. הוא בודק מאות סימנים, למשל:

  • רלוונטיות: כמה פעמים המילים שחיפשת מופיעות בדף, והאם הן בכותרת.
  • נדירות: מילה נדירה (כמו ״תלת-ממד״) חשובה יותר ממילה נפוצה (כמו ״של״).
  • פופולריות: הרעיון שהפך את גוגל למפורסם, PageRank. אם הרבה דפים מקשרים לדף מסוים, כנראה שהוא חשוב. וקישור מדף חשוב שווה יותר מקישור מדף לא חשוב. כמו שבכיתה, אם כולם ממליצים על מישהו, כנראה שכדאי להקשיב לו.
  • איכות ואמינות: האם האתר מהיר, בטוח (HTTPS), עובד בטלפון, ולא מלא בפרסומות מזויפות.
  • אתה: המיקום שלך, השפה שלך, ומה שחיפשת לפני כן.

היום גוגל גם משתמש ב-בינה מלאכותית כדי להבין מה התכוונת, ולא רק אילו מילים כתבת, ולפעמים הוא כותב לך תשובה מסוכמת בראש הדף בעזרת מודל שפה.

אבטחה באינטרנט

עכשיו כשאתה יודע איך דברים עוברים ברשת, כמה כללים: אל תמסור סיסמה לאף אחד, גם לא למי שטוען שהוא ״מהתמיכה״. בדוק שיש מנעול (HTTPS) לפני שאתה מקליד משהו. אל תוריד תוכנות ״חינמיות״ של משחקים בתשלום, כי הרבה פעמים יש בהן Malware (תוכנה זדונית). והפעל אימות דו-שלבי (2FA) בחשבונות חשובים.
