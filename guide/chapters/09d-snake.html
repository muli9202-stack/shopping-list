פרויקט מודרך: בנה סנייק

הגיע הזמן לבנות משחק שלם בעצמך, מהשורה הראשונה ועד שחברים משחקים בו. קודם תשחק, אחר כך נבנה אותו ביחד, חתיכה אחרי חתיכה.

קודם שחק

לפני שכותבים קוד: לתכנן

מתכנתים טובים לא מתחילים להקליד מיד. הם עונים קודם על שלוש שאלות:

  1. מה ה״מצב״ של המשחק? כלומר, איזה מידע צריך לזכור בכל רגע? הנחש (רשימה של משבצות), הכיוון שלו, מיקום התפוח, הניקוד, והאם המשחק נגמר.
  2. מה קורה בכל ״צעד״? הראש זז משבצת אחת בכיוון. אם הוא נכנס לקיר או לעצמו, המשחק נגמר. אם הוא אכל תפוח, הנחש גדל ותפוח חדש מופיע. אחרת, הזנב מתקצר במשבצת (כך הנחש ״זוחל״).
  3. איך השחקן שולט? החיצים משנים את הכיוון, אבל אסור להסתובב 180 מעלות ישר לתוך עצמך.
הטריק של הנחש

איך מזיזים נחש שלם? לא מזיזים כל חלק! מוסיפים ראש חדש לפני הראש הנוכחי (unshift), ומורידים את החלק האחרון (pop). כל שאר הגוף נשאר במקום, וזה נראה כאילו הנחש זחל. כשהוא אוכל, פשוט לא מורידים את הזנב, והנחש גדל באחד. זה פתרון אלגנטי שמשתמש במערך כמו ב״תור״ מפרק מבני הנתונים.

שלב 2: המצב של המשחק

הקנבס הוא 400×400 פיקסלים, ונחלק אותו לרשת של 20×20 משבצות, כל אחת 20 פיקסלים.

const canvas = document.getElementById("game");
const ctx = canvas.getContext("2d");   // ה"מכחול" שבעזרתו מציירים
const SIZE = 20, COLS = 20, ROWS = 20;

let snake = [{ x: 10, y: 10 }, { x: 9, y: 10 }, { x: 8, y: 10 }];   // הראש הוא הראשון
let dir = { x: 1, y: 0 };                                          // זז ימינה
let food = randomFood();
let score = 0;
let gameOver = false;

function randomFood() {
  return {
    x: Math.floor(Math.random() * COLS),
    y: Math.floor(Math.random() * ROWS),
  };
}

שלב 3: שליטה עם המקלדת

הבדיקה dir.y === 0 מונעת הסתובבות לאחור: אפשר לפנות למעלה רק אם כרגע לא זזים למעלה או למטה.

document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowUp"    && dir.y === 0) dir = { x: 0, y: -1 };
  if (e.key === "ArrowDown"  && dir.y === 0) dir = { x: 0, y: 1 };
  if (e.key === "ArrowLeft"  && dir.x === 0) dir = { x: -1, y: 0 };
  if (e.key === "ArrowRight" && dir.x === 0) dir = { x: 1, y: 0 };
});

שלב 4: חוקי המשחק (update)

function update() {
  const head = { x: snake[0].x + dir.x, y: snake[0].y + dir.y };   // הראש החדש

  const hitWall = head.x < 0 || head.y < 0 || head.x >= COLS || head.y >= ROWS;
  const hitSelf = snake.some(part => part.x === head.x && part.y === head.y);
  if (hitWall || hitSelf) {
    gameOver = true;
    return;
  }

  snake.unshift(head);                                  // הוסף ראש מקדימה

  if (head.x === food.x && head.y === food.y) {        // אכל תפוח?
    score++;
    document.getElementById("score").textContent = "ניקוד: " + score;
    food = randomFood();                                // (לא מורידים זנב = גדל)
  } else {
    snake.pop();                                        // הורד את הזנב
  }
}

שלב 5: ציור (draw)

function draw() {
  ctx.fillStyle = "#0b1a10";                                   // רקע
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  ctx.fillStyle = "red";                                       // תפוח
  ctx.fillRect(food.x * SIZE, food.y * SIZE, SIZE, SIZE);

  ctx.fillStyle = "lime";                                      // נחש
  snake.forEach(part => {
    ctx.fillRect(part.x * SIZE, part.y * SIZE, SIZE - 1, SIZE - 1);
  });

  if (gameOver) {
    ctx.fillStyle = "white";
    ctx.font = "40px sans-serif";
    ctx.textAlign = "center";
    ctx.fillText("Game Over", canvas.width / 2, canvas.height / 2);
  }
}

שלב 6: לולאת המשחק

בסנייק הנחש זז בקצב קבוע, אז במקום requestAnimationFrame נשתמש ב-setInterval, שמריץ פונקציה כל מספר קבוע של מילי-שניות:

function loop() {
  if (!gameOver) update();
  draw();
}
setInterval(loop, 120);   // 120 מילי-שניות = בערך 8 צעדים בשנייה

שמור, ולחץ פעמיים על הקובץ כדי לפתוח אותו בדפדפן. בנית משחק! 🐍

לא עובד?

  • בדוק שכל הקוד נמצא בין <script> ל-</script>.
  • בדוק שאין טעות כתיב: snake ו-Snake הם שני דברים שונים!

שדרוגים: הפוך את זה למשחק שלך

עכשיו החלק הכי חשוב: לשנות ולשפר לבד. כל שדרוג כאן הוא תרגיל, מקל לקשה:

  1. צבעים ועיצוב: ראש בצבע שונה מהגוף. תפוח עגול (ctx.arc). רשת משבצות ברקע.
  2. משחק חוזר: לחיצה על רווח אחרי Game Over מתחילה משחק חדש. (רמז: פונקציה reset() שמאפסת את כל משתני המצב.)
  3. שיא: שמירת הניקוד הגבוה עם localStorage.setItem("best", score), כך שהוא נשאר גם אחרי סגירת הדפדפן.
  4. מהירות עולה: כל 5 תפוחים המשחק מאיץ. (רמז: במקום setInterval השתמש ב-setTimeout שקורא לעצמו עם זמן שמתקצר.)
  5. באג לתיקון: אם לוחצים מהר מאוד ״למעלה״ ואז ״שמאלה״ כשהנחש זז ימינה, שני הכיוונים משתנים לפני שהנחש זז, והוא נכנס לעצמו! איך מתקנים? (רמז: תור של כיוונים, כמו במשחק שבראש הפרק.)
  6. קירות שקופים: יציאה מצד אחד מחזירה מהצד השני. (רמז: %)
  7. צלילים: צליל כשאוכלים תפוח (ראה פרק הצליל).
  8. טלפון: שליטה בהחלקת אצבע (touchstart ו-touchend, והשוואת ההפרש ב-x וב-y).
  9. אתגר גדול: מכשולים, שלבים, או מצב שני שחקנים על אותה מקלדת (חיצים מול WASD).
