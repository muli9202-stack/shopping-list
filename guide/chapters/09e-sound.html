צליל ומוזיקה

עצום את העיניים ותחשוב על מריו. שמעת את המנגינה, נכון? צליל הוא חצי מהזיכרון שלנו ממשחקים. בוא נבין מה הוא, ונייצר אותו מקוד.

מה זה צליל?

צליל הוא רעידות של אוויר. כשמשהו רוטט (מיתר של גיטרה, הממברנה של רמקול), הוא דוחף את האוויר קדימה ואחורה, והרעידה הזאת מגיעה לאוזן. שני דברים קובעים איך צליל נשמע:

  • Frequency (תדר): כמה פעמים בשנייה הרעידה חוזרת. נמדד בהרץ (Hz). תדר גבוה = צליל גבוה (צפצוף), תדר נמוך = צליל נמוך (בס). אוזן אנושית שומעת בערך מ-20 Hz ועד 20,000 Hz. התו ״לה״ שכל התזמורות מכוונות לפיו הוא בדיוק 440 Hz.
  • Amplitude (עוצמה): כמה חזקה הרעידה. גדול יותר = רועש יותר.

וצורת הגל קובעת את ה״צבע״ של הצליל: למה פסנתר וגיטרה שמנגנים את אותו תו נשמעים שונה. גל סינוס רך וטהור, גל ריבוע נשמע כמו משחקי נינטנדו ישנים, וגל משור חד ״ורועש״.

איך מחשב שומר צליל

המיקרופון הופך את רעידות האוויר לחשמל, והמחשב מודד את גובה הגל הרבה פעמים בשנייה ושומר כל מדידה כמספר. כל מדידה נקראת Sample (דגימה). באיכות של דיסק: 44,100 דגימות בשנייה. כך שדקה של שיר היא בערך 5 מיליון מספרים (לכל אוזן!). קבצים כמו MP3 ו-OGG דוחסים את זה בחוכמה: הם זורקים פרטים שהאוזן האנושית ממילא לא שומעת.

טריקים של מעצבי סאונד

  • וריאציה: אם כל צעד נשמע בדיוק אותו דבר, המוח שם לב וזה נשמע רובוטי. לכן משנים קצת את הגובה והעוצמה בכל פעם (pitch = 1 + random(-0.1, 0.1)), או מחזיקים 4-5 הקלטות שונות ובוחרים אקראית.
  • צליל תלת-ממדי: צליל מימין נשמע יותר באוזן ימין, צליל רחוק שקט יותר ו״עמום״. מנועי משחק עושים את זה אוטומטית אם שמים את הצליל במקום בעולם.
  • מוזיקה דינמית: משחקים כמו GTA משנים את המוזיקה לפי מה שקורה: מוסיפים תופים כשהמשטרה רודפת, ומורידים כשבורחים.
  • Ducking: כשדמות מדברת, המוזיקה יורדת מעט כדי שישמעו אותה.
  • שקט: לפעמים השקט הוא האפקט החזק ביותר, במיוחד במשחקי אימה.

הרדיו של GTA

בסדרת GTA יש עשרות תחנות רדיו, כל אחת עם סגנון מוזיקה, שדרנים, פרסומות מזויפות מצחיקות ותוכניות אירוח. הפרטים הקטנים: הרדיו ממשיך ״לשדר״ גם כשאתה לא ברכב, כך שכשאתה נכנס לרכב אחר, השיר ממשיך מאיפה שהיה. השדרנים לפעמים מדברים על דברים שעשית במשימות. ובשביל להשתמש בשירים אמיתיים, Rockstar משלמת לאמנים ולחברות התקליטים על רישיונות.

צליל בקוד (JavaScript)

// הדרך הפשוטה: לנגן קובץ
const coin = new Audio("coin.mp3");
coin.play();

// הדרך המתקדמת: לייצר צליל מאפס עם Web Audio API
const ac = new AudioContext();
const osc = ac.createOscillator();   // "מתנד": מייצר גל
osc.type = "square";                     // צורת הגל
osc.frequency.value = 440;                 // תדר: לה
osc.connect(ac.destination);             // חבר לרמקולים
osc.start();
osc.stop(ac.currentTime + 0.3);         // עצור אחרי 0.3 שניות
כלל של דפדפנים

דפדפנים לא מרשים לאתר להשמיע צליל לפני שהמשתמש לחץ על משהו, כדי שאתרים לא יפתיעו אותך ברעש. לכן משחקי דפדפן מתחילים תמיד במסך ״לחץ כדי להתחיל״.
