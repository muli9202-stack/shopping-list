פרק 6 · HTML, CSS, JavaScript ואיך מעלים אתר לאוויר

בניית אתרים

כל אתר בעולם, מגוגל ועד יוטיוב, בנוי משלוש שפות בלבד. אחרי הפרק הזה תוכל לבנות אתר משלך ולשלוח את הקישור לחברים.

שלושת השכבות של כל אתר

הדרך הכי קלה להבין אתר היא לחשוב על בית:

שפהבבית זה...מה היא עושה
HTMLהשלד: קירות, חדרים, דלתותהמבנה והתוכן: כותרות, פסקאות, תמונות, כפתורים, קישורים.
CSSהצבע, הרהיטים והעיצובאיך הכול נראה: צבעים, גופנים, גדלים, מיקום, אנימציות.

HTML: המבנה

HTML זה ראשי תיבות של HyperText Markup Language, ״שפת סימון לטקסט עם קישורים״. זו לא בדיוק שפת תכנות (אין בה תנאים ולולאות), אלא שפת סימון: אתה ״עוטף״ תוכן בTag (תגית) שאומרת מה הוא.

<!DOCTYPE html>
<html lang="he" dir="rtl">          <!-- dir="rtl" = מימין לשמאל, לעברית -->
  <head>
    <meta charset="UTF-8">          <!-- כדי שעברית תוצג נכון -->
    <title>האתר שלי</title>         <!-- מה שכתוב בלשונית -->
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>שלום, אני נועם</h1>         <!-- כותרת ראשית -->
    <p>אני לומד לבנות משחקים.</p>   <!-- פסקה -->
    <img src="me.jpg" alt="תמונה שלי">
    <a href="https://example.com">קישור</a>
    <button id="btn">לחץ עליי</button>
    <script src="app.js"></script>
  </body>
</html>

שים לב לחוקיות: רוב התגיות באות בזוגות, תגית פתיחה <p> ותגית סגירה </p> (עם לוכסן). מה שבאמצע הוא התוכן. לתגיות יש Attribute (תכונה), כמו src (מקור התמונה) או href (לאן הקישור מוביל).

התגיות הכי חשובות

CSS: העיצוב

CSS זה Cascading Style Sheets, ״גיליונות סגנון מדורגים״. ב-CSS אתה בוחר מה לעצב (Selector, בורר), ואיך (תכונה וערך):

h1 {                          /* כל הכותרות הראשיות */
  color: darkblue;            /* צבע טקסט */
  font-size: 40px;            /* גודל: 40 פיקסלים */
}
.card {                       /* כל מי שיש לו class="card" */
  background: #ffe29f;        /* צבע רקע בקוד הקסדצימלי */
  padding: 20px;              /* ריווח פנימי */
  margin: 10px;               /* ריווח חיצוני */
  border-radius: 16px;        /* פינות מעוגלות */
}
#btn:hover {                  /* האלמנט עם id="btn", כשהעכבר מעליו */
  transform: scale(1.1);      /* הגדל ב-10% */
}

כל אלמנט בדף הוא בעצם קופסה. ל-CSS יש מושג בשם מודל הקופסה (Box Model): התוכן באמצע, מסביבו ריווח פנימי (padding), מסביבו מסגרת (border), ומסביב לכל זה ריווח חיצוני (margin). לסידור קופסאות אחת ליד השנייה משתמשים בכלים בשם Flexbox ו-Grid.

נסה עכשיו! שנה את הקוד במעבדה וראה את התוצאה מיד:

רעיונות לניסוי במעבדה
  • שנה את #1e4fd0 בכפתור לצבע אחר, למשל crimson או #00aa66.
  • הוסף עוד <li> לרשימה.
  • שנה את border-radius ל-0 ואחר כך ל-50px.
  • הוסף <h2> עם כותרת משנה.

אתר שעובד גם בטלפון

יותר ממחצית הגלישה בעולם היא מטלפונים. אתר שנראה טוב גם במסך גדול וגם במסך קטן נקרא Responsive (רספונסיבי, מגיב). ב-CSS עושים את זה עם Media Query (שאילתת מדיה):

@media (max-width: 600px) {   /* רק במסכים צרים מ-600 פיקסלים */
  h1 { font-size: 26px; }
  .menu { display: none; }
}

JavaScript: להפיח חיים

כבר למדת JavaScript. באתר, JavaScript מתחבר ל-HTML דרך ה-DOM. הנה אתר קטן ושלם: כפתור שמגריל מספר כמו קובייה.

<button id="roll">הטל קובייה</button>
<p id="result"></p>

<script>
  const btn = document.getElementById("roll");
  const out = document.getElementById("result");
  btn.addEventListener("click", () => {
    const n = Math.floor(Math.random() * 6) + 1;
    out.textContent = "יצא: " + n;
  });
</script>

שמור את זה בקובץ בשם index.html במחשב, לחץ עליו פעמיים, והוא ייפתח בדפדפן. בנית אתר.

Frontend ו-Backend

לאתרים גדולים יש שני צדדים:

  • Frontend (צד לקוח, ״חזית״): כל מה שרץ בדפדפן שלך ומה שאתה רואה. HTML, CSS, JavaScript.
  • Backend (צד שרת, ״מאחורי הקלעים״): מה שרץ על השרת. שומר משתמשים וסיסמאות, מעבד תשלומים, שולף מידע מDatabase (מסד נתונים). כתוב ב-JavaScript (עם Node.js), Python, Java, Go ועוד.
  • מי שיודע את שני הצדדים נקרא Full Stack developer (מפתח ״כל השכבות״).

הצדדים מדברים ביניהם דרך API: ״תפריט״ של בקשות שהשרת יודע לענות עליהן. למשל, אפליקציית מזג אוויר שולחת ל-API בקשה ״מה מזג האוויר בחיפה?״ ומקבלת תשובה בפורמט בשם JSON, שנראה בדיוק כמו אובייקט של JavaScript:

{ "city": "חיפה", "temp": 27, "sky": "בהיר" }

ספריות ו-Frameworks

אף אחד לא בונה הכול מאפס. מתכנתים משתמשים בקוד שאחרים כתבו ושיתפו:

  • Library (ספרייה): אוסף קוד מוכן שאתה קורא לו כשצריך. למשל Three.js לגרפיקה תלת-ממדית (בה בנינו את העיר בפרק המשחקים).
  • Framework (מסגרת עבודה): ״שלד״ שלם שאתה בונה בתוכו לפי החוקים שלו.

הפופולריים ביותר לאתרים היום: React (ריאקט, של מטא, הכי נפוץ), Next.js (מבוסס React, לאתרים שלמים), Vue (ויו), Svelte (סוולט) ו-Angular (אנגולר, של גוגל). לעיצוב מהיר משתמשים הרבה ב-Tailwind CSS. את כולם מתקינים עם כלי בשם npm, שהוא ״חנות האפליקציות״ של קוד JavaScript, עם מיליוני חבילות.

אל תמהר ל-React

הרבה מתחילים קופצים ישר ל-React ומתבלבלים, כי הם לא מבינים מה קורה מתחת. בנה קודם 3-5 אתרים קטנים ב-HTML, CSS ו-JavaScript רגילים (״Vanilla JS״). כשתרגיש שאתה חוזר על אותו קוד שוב ושוב, זה הזמן ל-React. אז תבין למה הוא קיים.

איך מעלים אתר לאינטרנט

אתר שיושב רק במחשב שלך רואה רק אתה. כדי שכל העולם יראה, צריך Hosting (אחסון): לשים את הקבצים על שרת שמחובר לאינטרנט 24/7. ההעלאה עצמה נקראת Deploy (פריסה). היום יש דרכים חינמיות לגמרי לאתרים פשוטים:

  • GitHub Pages: מעלים את הקוד ל-GitHub, ומקבלים כתובת כמו yourname.github.io. (המדריך הזה, אגב, מתפרסם בדיוק ככה.)
  • Netlify ו-Vercel: גוררים תיקייה, ותוך דקה האתר באוויר.
  • Cloudflare Pages: דומה, מהיר מאוד.

אם תרצה כתובת משלך, כמו noam.dev, קונים Domain בכמה עשרות שקלים לשנה. (שים לב: לקנות משהו באינטרנט צריך הורה.)
