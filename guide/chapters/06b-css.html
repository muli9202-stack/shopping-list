עיצוב ו-CSS לעומק

אתר שעובד זה התחלה. אתר שאנשים אוהבים להשתמש בו דורש עיצוב. הנה הכלים והעקרונות שמעצבים ומפתחים משתמשים בהם כל יום.

Flexbox: סידור בשורה או בעמודה

בעבר, לסדר שלושה כפתורים אחד ליד השני במרכז היה כאב ראש. היום יש Flexbox. שמים display: flex על ה״מיכל״, והילדים שלו מסתדרים בשורה. יש שני צירים: הציר הראשי (הכיוון של השורה, נשלט ע״י justify-content) והציר השני (ניצב לו, נשלט ע״י align-items).

המתכון למרכז מושלם

השאלה הכי נפוצה בתולדות ה-CSS, ״איך ממרכזים משהו?״, נפתרה בשלוש שורות: display: flex; justify-content: center; align-items: center;

Grid: טבלאות של פריסה

כש-Flexbox מסדר בציר אחד, Grid מסדר בשניים: שורות ועמודות ביחד. מושלם לגלריות, דשבורדים ומבנה של דף שלם.

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));   /* כמה עמודות שנכנסות, כל אחת לפחות 200px */
  gap: 16px;
}

השורה הזאת לבדה יוצרת גלריה שמסתדרת לבד: 4 עמודות במחשב, 2 בטאבלט ואחת בטלפון, בלי אף Media Query. הכרטיסים של ״מפת המדריך״ בפרק הפתיחה בנויים בדיוק ככה.

צבע

ראית בפרק 1 שכל צבע במסך הוא שלושה מספרים: אדום, ירוק וכחול. ב-CSS כותבים צבע בכמה דרכים:

כללי אצבע של מעצבים:

  • פלטה קטנה: צבע רקע, צבע טקסט, צבע ״דגש״ אחד (לכפתורים וקישורים), ואולי שניים-שלושה צבעי מצב (ירוק להצלחה, אדום לשגיאה). לא יותר.
  • ניגודיות (Contrast): טקסט אפור בהיר על לבן נראה ״אלגנטי״ ואי אפשר לקרוא אותו. חשוב במיוחד לאנשים עם ראייה חלשה.
  • מצב כהה: היום מצופה שאתר יעבוד גם בבהיר וגם בכהה. משתמשים בCSS Variables (--bg, --text) ומחליפים אותם. המדריך הזה בנוי כך: נסה להחליף ערכת צבעים בפרופיל שלך (הכפתור ״רמה״ למעלה).

טיפוגרפיה: האומנות של טקסט

Typography (טיפוגרפיה) היא הבחירה של גופנים, גדלים ורווחים. 90% מכל אתר הוא טקסט, אז זה אולי הדבר החשוב ביותר בעיצוב.

  • שני גופנים לכל היותר: אחד לכותרות, אחד לטקסט. Google Fonts מציע מאות גופנים חינמיים, כולל עשרות בעברית (Rubik, Heebo, Assistant, Secular One ועוד).
  • גודל טקסט: 16px לפחות לטקסט רגיל.
  • אורך שורה: 50-75 תווים. שורות ארוכות מדי מעייפות את העין.
  • רווח בין שורות (line-height): בערך 1.5 עד 1.8 לטקסט רגיל.
  • היררכיה: הקורא צריך להבין מה חשוב תוך שנייה, לפי גודל ומשקל.

אנימציות ומעברים

.button {
  transition: transform 0.2s ease-out, background 0.2s;   /* כל שינוי יקרה בהדרגה */
}
.button:hover {
  transform: translateY(-3px) scale(1.05);               /* קופץ קצת למעלה ומתנפח */
}

@keyframes pulse {                                        /* אנימציה עם שלבים */
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.4; }
}
.loading { animation: pulse 1.2s infinite; }

ה-ease-out שם? זו בדיוק פונקציית Easing מהפרק על מתמטיקה! כלל חשוב: אנימציות קצרות (0.15 עד 0.3 שניות) מרגישות מהירות ומקצועיות. ארוכות מדי מרגישות איטיות. ותמיד לכבד משתמשים שביקשו פחות תנועה (prefers-reduced-motion), כי לחלק מהאנשים תנועה גורמת לסחרחורת.

נגישות: אתר לכולם

Accessibility (נגישות, מקוצר a11y) היא לבנות אתרים שגם אנשים עם מוגבלויות יכולים להשתמש בהם: עיוורים שמשתמשים בקורא מסך שמקריא את הדף, אנשים שמשתמשים רק במקלדת, עיוורי צבעים. בישראל יש על זה גם חוק. היסודות:

  • alt לכל תמונה, שמתאר מה יש בה.
  • להשתמש בתגיות הנכונות: <button> לכפתור (לא <div> עם לחיצה).
  • שכל דבר יעבוד גם עם Tab ו-Enter, ושיהיה סימון ברור של מה שנבחר.
  • לא להעביר מידע רק דרך צבע (״השדות האדומים שגויים״ לא עוזר לעיוור צבעים).

כלים של מעצבים

  • Figma: הכלי הפופולרי לעיצוב ממשקים. חינמי למתחילים, עובד בדפדפן, ואפשר לעבוד בו ביחד בזמן אמת.
  • Tailwind CSS: ספרייה שבה כותבים עיצוב כ״מחלקות קטנות״ ישר ב-HTML: class="p-4 bg-blue-500 rounded-xl". מאוד פופולרי.
  • Coolors ו-Adobe Color: מחוללי פלטות צבעים.
  • Dribbble ו-Behance: השראה מעבודות של מעצבים.
