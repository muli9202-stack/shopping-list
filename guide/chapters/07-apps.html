פרק 7 · אפליקציות לטלפון, שרתים, מסדי נתונים וחנויות

בניית אפליקציות

אפליקציה היא תוכנה שרצה בטלפון או במחשב. בפרק הזה תבין את כל הדרכים לבנות אחת, ואיך היא מגיעה לחנות האפליקציות.

מה זו בעצם ״אפליקציה״?

App זה קיצור של Application, יישום. כל תוכנה שמשתמשים בה היא אפליקציה: וואטסאפ, אינסטגרם, מחשבון, וגם משחקים. יש שלושה סוגים עיקריים:

המדריך הזה יושב בתוך פרויקט של אפליקציית רשימת קניות, שהיא בדיוק PWA: אתר שנכתב ב-TypeScript עם React, שאפשר להוסיף למסך הבית בטלפון, שומר מידע במכשיר, ומסנכרן רשימה משותפת בין בני משפחה דרך Firebase. כל מה שמתואר בפרק הזה קיים בה.

הכלים לכל סוג

אייפון (iOS)

שפה: Swift. ספריית עיצוב: SwiftUI. תוכנת פיתוח: Xcode (אקס-קוד), שרצה רק על מחשב מק. זה אחד המחסומים הגדולים: בשביל לפתח לאייפון ישירות צריך מק.

אנדרואיד

שפה: Kotlin. ספריית עיצוב: Jetpack Compose. תוכנת פיתוח: Android Studio, שרצה על כל מחשב (ווינדוס, מק, לינוקס) ובחינם.

שניהם ביחד

  • Flutter (פלאטר, של גוגל): שפת Dart. מצייר את כל המסך בעצמו, ולכן נראה זהה בכל מכשיר. מאוד פופולרי.
  • React Native (ריאקט נייטיב, של מטא): כותבים ב-JavaScript/TypeScript, כמו React באתרים. אם כבר למדת ווב, זה המעבר הטבעי. בשילוב עם Expo אפשר לראות את האפליקציה בטלפון שלך תוך דקות, בלי מק.
  • .NET MAUI (של מיקרוסופט): כותבים ב-C#.
מה אנחנו ממליצים לך

אתה כבר לומד JavaScript. אז: בנה קודם אתר, הפוך אותו ל-PWA, ואז עבור ל-React Native עם Expo. ככה אתה משתמש באותה שפה לאתרים, לאפליקציות וגם לשרת. אם אתה מעדיף משהו אחר, Flutter היא בחירה מצוינת לא פחות.

איך בנויה אפליקציה אמיתית

קח לדוגמה אפליקציה כמו אינסטגרם. יש בה:

  1. ממשק משתמש, UI (User Interface): המסכים, הכפתורים, הפיד. זה ה-Frontend.
  2. חוויית משתמש, UX (User Experience): כמה קל ונעים להשתמש. האם ברור איפה ללחוץ? כמה צעדים לוקח להעלות תמונה? אנשים שמתמחים בזה נקראים מעצבי UX/UI, ומשתמשים בכלי בשם Figma.
  3. שרת (Backend): מקבל את התמונה שהעלית, שומר אותה, ושולח אותה לעוקבים.
  4. מסד נתונים (Database): שומר מי אתה, מי העוקבים שלך, אילו תמונות העלית ומי עשה לייק.
  5. הזדהות (Authentication): הרשמה, התחברות, סיסמאות. בודק מי אתה.
  6. התראות (Push Notification): ההודעות שקופצות גם כשהאפליקציה סגורה.
  7. אחסון קבצים: תמונות ווידאו יושבים ב״ענן״.

מסדי נתונים

Database (מסד נתונים) זו תוכנה ששומרת מידע בצורה מסודרת, ויודעת למצוא אותו מהר מאוד. יש שני סוגים עיקריים:

  • מסד נתונים טבלאי (SQL): המידע יושב בטבלאות, כמו אקסל. לכל משתמש יש שורה, ולכל תכונה (שם, גיל, אימייל) יש עמודה. שואלים אותו בשפת SQL: SELECT name FROM users WHERE age > 13; (״תבחר שמות מטבלת המשתמשים איפה שהגיל מעל 13״). דוגמאות: PostgreSQL, MySQL, SQLite.
  • מסד נתונים לא-טבלאי (NoSQL): המידע שמור כ״מסמכים״, דומים לאובייקטים של JavaScript. גמיש יותר. דוגמאות: Firebase Firestore, MongoDB.

קיצור דרך: Backend מוכן

לכתוב שרת, מסד נתונים, התחברות והתראות מאפס זו עבודה של חודשים. לכן יש שירותים שנותנים את כל זה מוכן, נקראים BaaS (Backend as a Service, ״צד שרת כשירות״):

  • Firebase (של גוגל): מסד נתונים בזמן אמת, התחברות עם גוגל, אחסון קבצים, התראות. יש מסלול חינמי נדיב.
  • Supabase: חלופה פתוחה ל-Firebase, מבוססת על מסד נתונים SQL.

עם אחד מהם, מתכנת אחד יכול לבנות אפליקציה עם משתמשים וצ׳אט בזמן אמת בסוף שבוע.

שלבי בניית אפליקציה, מהרעיון ועד החנות

  1. רעיון ובעיה: איזו בעיה האפליקציה פותרת? למי? (״אין לי דרך קלה לעקוב אחרי שיעורי הבית״.)
  2. סקיצה: צייר על דף (או ב-Figma) את המסכים. זה נקרא Wireframe (שרטוט שלד).
  3. גרסה מינימלית: בנה רק את הדבר הכי חשוב. זה נקרא MVP (Minimum Viable Product, מוצר מינימלי שעובד). לא מוסיפים עדיין פיצ׳רים.
  4. בדיקות: תן לחברים ולמשפחה לנסות. תראה איפה הם מתבלבלים. תקן באגים.
  5. שיפור: הוסף פיצ׳רים אחד-אחד, לפי מה שמשתמשים באמת צריכים.
  6. פרסום: מעלים לחנויות.

איך אפליקציות מרוויחות כסף

  • תשלום חד-פעמי: קונים את האפליקציה פעם אחת.
  • Freemium: חינם, עם תוספות בתשלום (In-App Purchase, רכישה בתוך האפליקציה). ככה עובדים רוב משחקי הטלפון.
  • מנוי (Subscription): תשלום כל חודש, כמו ספוטיפיי.
  • פרסומות: חינם, ומרוויחים מפרסומות.
פרטיות ואחריות

ברגע שהאפליקציה שלך שומרת מידע של אנשים אחרים (שמות, תמונות, אימיילים), יש לך אחריות. לעולם אל תשמור סיסמאות כטקסט רגיל (משתמשים בHash, או עדיף בשירות התחברות מוכן כמו Firebase Auth). אל תאסוף מידע שאתה לא צריך. ואל תשים מפתחות סודיים (API Key) בתוך קוד שכולם יכולים לראות.
