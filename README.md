# רשימת קניות

אפליקציית ווב (PWA) בעברית לניהול רשימות קניות בנטו חיסכון וביש חסד.

## פיתוח

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לתיקיית dist
```

## התקנה בטלפון

האפליקציה מתפרסמת אוטומטית ל-GitHub Pages בכל push (ראו `.github/workflows/deploy.yml`).
פותחים את הכתובת בטלפון ובוחרים "הוספה למסך הבית" (באייפון: שיתוף ← הוספה למסך הבית).

כל הנתונים נשמרים במכשיר (IndexedDB). כל שעה נשמר גיבוי אוטומטי במכשיר, ובמסך ההגדרות אפשר לייצא לאקסל
(כולל הורדה אוטומטית כל שעה כשהאפליקציה פתוחה) ולשחזר מקובץ האקסל.

## רשימה משותפת (Firebase)

הסנכרון בין טלפונים עובד מול פרויקט Firebase של המשתמש. ההוראות להגדרה מופיעות במסך ההגדרות.
כללי האבטחה של Firestore (מוצגים גם באפליקציה) מתירים גישה רק למי שמחזיק בקוד המשפחתי:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{code}/{col}/{docId} {
      allow read, write: if code.size() >= 20;
    }
  }
}
```

בדיקה מקומית מול האמולטור: `http://localhost:4173/?firestoreEmulator=127.0.0.1:8085`.

## המטבח שלי (`/kitchen/`)

אפליקציה שנייה באותו אתר: סרטונים, מתכונים ותכנון שולחן שבת וחג. נפתחת בכתובת האתר + `kitchen/`
(למשל `https://<user>.github.io/shopping-list/kitchen/`), וגם אותה אפשר להוסיף למסך הבית.
הקוד נמצא ב-`kitchen/src`, והנתונים נשמרים במכשיר (IndexedDB) בנפרד מרשימת הקניות. גיבוי ושחזור — במסך ההגדרות.

- שם הסרטון ותמונת הכותרת נמשכים מיוטיוב בלי מפתח (oEmbed).
- משיכה אוטומטית של תיאור הסרטון (ממנו נבנה המתכון) דורשת מפתח YouTube Data API חינמי; בלי מפתח מדביקים את התיאור ידנית.
- המתכון נבנה רק ממה שכתוב בתיאור. אם אין בו מצרכים ושלבי הכנה, המתכון מסומן "חסר".
