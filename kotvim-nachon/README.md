אפליקציית אנדרואיד בעברית שמלמדת ילדים לכתוב בלי שגיאות כתיב – דרך משחקונים (חלקם בתלת-ממד), טריקים מונפשים, הכתבות קוליות, תיקון סיפורים עם AI וחדר תלת-ממדי שקונים אליו דברים בנקודות.

## 🚀 איך מקבלים את קובץ ה-‎.aab (הדרך הקלה)

הקובץ נבנה אוטומטית ב-GitHub בכל פעם שמשהו משתנה בתיקייה הזו. לא צריך להתקין כלום על המחשב.

### שלב 1 – להוסיף את מפתח החתימה (פעם אחת בלבד)

גוגל פליי מקבלת רק קובץ חתום. קיבלתם ממני שני דברים: קובץ טקסט עם המפתח (`upload-keystore-base64.txt`) וסיסמה.
**שמרו את שניהם במקום בטוח** – בלי המפתח הזה לא תוכלו להעלות עדכונים (אם הוא אבד, אפשר לבקש מגוגל לאפס אותו).

1. ב-GitHub נכנסים למאגר ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**.
2. מוסיפים שני סודות:
   - שם: `ANDROID_KEYSTORE_BASE64` – ערך: כל התוכן של הקובץ `upload-keystore-base64.txt`
   - שם: `ANDROID_KEYSTORE_PASSWORD` – ערך: הסיסמה

### שלב 2 – להוריד את הקובץ

1. במאגר ב-GitHub לוחצים על **Actions** ← **כותבים נכון – Android App Bundle**.
2. לוחצים **Run workflow** (או פשוט מחכים לריצה האחרונה).
3. כשהריצה ירוקה ✅, נכנסים אליה ולמטה תחת **Artifacts** מורידים את `kotvim-nachon-aab-…`. בתוך ה-zip נמצא `app-release.aab`.

> בלי שום הגדרה נוספת האפליקציה כבר עובדת: שמירה בטלפון, בדיקת כתיב בסיסית במכשיר, ופרסומות **ניסיון** של גוגל. השלבים הבאים מוסיפים ענן, AI ופרסומות אמיתיות.

## ☁️ חיבור לענן והתחברות עם Google (Firebase)

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) ← **Add project** ← שם: `kotvim-nachon`.
2. **Build ← Authentication ← Get started**: מפעילים **Google** ו-**Email/Password**.
3. **Build ← Firestore Database ← Create database** (אזור `eur3` או `europe-west1`) ← Production mode.
   בלשונית **Rules** מדביקים את התוכן של הקובץ `firestore.rules` ולוחצים Publish.
4. **Project settings (⚙️) ← Your apps**:
   - **אפליקציית ווב (`</>`)** – נותנים שם, ומעתיקים את אובייקט `firebaseConfig` (מ-`{` עד `}`). שומרים אותו כסוד ב-GitHub בשם `FIREBASE_WEB_CONFIG`, בפורמט JSON (מרכאות סביב המפתחות), למשל:
     `{"apiKey":"...","authDomain":"...","projectId":"...","storageBucket":"...","messagingSenderId":"...","appId":"..."}`
   - **אפליקציית אנדרואיד** – Package name: `com.kotvimnachon.app`. מוסיפים טביעות **SHA-1** (ראו למטה), מורידים את `google-services.json` ושומרים את **כל התוכן שלו** כסוד בשם `GOOGLE_SERVICES_JSON`.
5. **טביעות SHA-1** (בלעדיהן כפתור Google לא יעבוד):
   - של מפתח ההעלאה – נתתי לכם אותה יחד עם המפתח.
   - של גוגל פליי – אחרי ההעלאה הראשונה: Play Console ← האפליקציה ← **Test and release ← App integrity ← App signing** ← מעתיקים את ה-SHA-1 של "App signing key certificate" ומוסיפים גם אותו ב-Firebase. אחרי זה מורידים שוב את `google-services.json` ומעדכנים את הסוד.
6. מריצים שוב את ה-workflow ב-Actions – והגרסה החדשה כוללת ענן והתחברות עם Google.

## 🤖 הפעלת ה-AI (תיקון סיפורים וסיכום להורים)

ה-AI רץ בשרת (Cloud Functions) כדי שהמפתח לא יהיה בתוך האפליקציה. זה דורש תוכנית **Blaze** ב-Firebase (תשלום לפי שימוש; לרוב זניח).

1. פותחים מפתח API ב-[console.anthropic.com](https://console.anthropic.com) (Claude).
2. במחשב עם Node.js 22:
   ```bash
   npm install -g firebase-tools
   firebase login
   cd kotvim-nachon
   firebase use --add            # בוחרים את הפרויקט
   firebase functions:secrets:set ANTHROPIC_API_KEY   # מדביקים את המפתח
   cd functions && npm install && cd ..
   firebase deploy --only functions,firestore:rules
   ```
3. זהו. כשההורה מחובר, סיפורים נבדקים עם Claude (רק הטקסט והכיתה נשלחים – בלי שם הילד), ובלוח ההורים הכפתור "עדכון" מביא סיכום AI. בלי חיבור – יש בדיקה בסיסית במכשיר.

## 💰 חיבור AdMob (פרסומות)

1. נכנסים ל-[admob.google.com](https://admob.google.com) ← **Apps ← Add app** ← Android ← "האם האפליקציה בחנות?" – בהתחלה "לא".
2. מעתיקים את ה-**App ID** (נראה כך: `ca-app-pub-1234567890123456~1234567890`) ושומרים כסוד בשם `ADMOB_APP_ID`.
3. **Ad units ← Add ad unit ← Interstitial** ← מעתיקים את ה-ID (עם `/`) ושומרים כסוד בשם `ADMOB_INTERSTITIAL_ID`.
4. ב-AdMob: **Blocking controls ← Content** – מסמנים דירוג מקסימלי **G**. ב-**App settings** מסמנים שהאפליקציה מיועדת לילדים (Designed for Families / child-directed).
5. מריצים שוב את ה-workflow.

**מה כבר מוגדר בקוד (מדיניות Families של גוגל):** כל בקשת פרסומת מסומנת child-directed + under age of consent, דירוג G, ללא פרסום מותאם אישית (npa), הרשאת Advertising ID מוסרת מהאפליקציה, ופרסומת מוצגת **רק בין שלבים** (אחרי שלב או אימון, לכל היותר פעם ב-4 דקות) – אף פעם לא בזמן למידה או כתיבה.

## 📱 העלאה לגוגל פליי – שלב אחר שלב

1. נרשמים ל-[Play Console](https://play.google.com/console) (תשלום חד-פעמי של 25$). בחשבון אישי חדש גוגל דורשת בדיקה סגורה עם 12 בודקים במשך 14 יום לפני פרסום לכולם.
2. **Create app**: שם `כותבים נכון`, שפת ברירת מחדל עברית, App, Free.
3. **Test and release ← Testing ← Internal testing ← Create new release**:
   - מאשרים **Play App Signing** (גוגל שומרת את מפתח ההפצה; המפתח שלכם הוא רק מפתח העלאה).
   - גוררים את `app-release.aab` ← Next ← Save ← Publish.
4. **Grow users ← Store presence ← Main store listing**:
   - תיאור קצר ומלא (אפשר להשתמש בטבלה שלמעלה).
   - אייקון: `store/icon-512.png` · תמונת נושא: `store/feature-graphic.png` · צילומי מסך מהטלפון (לפחות 2).
5. **Policy ← App content** – ממלאים הכול:
   - **Privacy policy**: כתובת לדף הפרטיות. הכי פשוט: `firebase deploy --only hosting` ואז הכתובת היא `https://<project-id>.web.app/privacy.html` (הקובץ נמצא ב-`public/privacy.html`).
   - **Ads**: Yes, my app contains ads.
   - **Target audience and content**: קבוצות גיל **5 ומטה, 6–8, 9–12** (לפי מה שמתאים). מסמנים שהאפליקציה משתתפת ב-**Families**. עונים שה-SDK של הפרסומות הוא AdMob (מאושר ל-Families).
   - **Content rating**: ממלאים את השאלון (קטגוריה: Education / Reference). אין אלימות, אין צ׳אט, אין רכישות.
   - **Data safety**: נאסף – כתובת מייל של ההורה (לחשבון), שם פרטי/כינוי של ילד ונתוני למידה (פונקציונליות האפליקציה), הודעות/טקסט שהילד כתב (נשלח לעיבוד AI, לא נשמר אצל ספק ה-AI מעבר לנדרש); הנתונים מוצפנים בהעברה; ההורה יכול לבקש מחיקה. פרסומות: AdMob ללא Advertising ID.
   - **Government apps / Financial / Health**: No.
6. **Test and release ← Production ← Create new release** ← בוחרים את אותו ה-bundle ← שולחים לבדיקה. הבדיקה של גוגל לוקחת בדרך כלל כמה ימים.
7. **עדכונים:** כל שינוי בקוד → ה-workflow בונה אוטומטית `.aab` עם מספר גרסה גבוה יותר → מורידים ומעלים ב-Production ← Create new release.

## 👩‍💻 למפתחים

```bash
cd kotvim-nachon
npm install
npm run dev        # הרצה בדפדפן
npm test           # בדיקות למנוע ניתוח הטעויות
npm run build      # typecheck + build
npm run android:sync && npx cap open android   # פתיחה ב-Android Studio
```

קובץ `.env.local` לפיתוח מקומי (לא חובה):
```
VITE_FIREBASE_CONFIG={"apiKey":"...","projectId":"..."}
```

**מבנה:** React + TypeScript + Vite, עטוף ב-Capacitor לאנדרואיד · three.js למשחקים ולחדר · Firebase (Auth, Firestore, Functions) · Claude דרך Cloud Function (`functions/src/index.ts`) · AdMob דרך `@capacitor-community/admob` · הקראה קולית דרך מנוע ה-TTS של אנדרואיד (`he-IL`).

| תיקייה | תוכן |
|---|---|
| `src/data` | מאגר המילים לפי נושא וכיתה, הכתבות, רעיונות לסיפורים, הגדרת הנושאים |
| `src/engine` | ניתוח טעויות (יישור טקסטים, סיווג לפי נושא), יצירת שאלות, התקדמות ועולמות, בודק כתיב לא-מקוון |

| `android` | פרויקט האנדרואיד (Capacitor) |
